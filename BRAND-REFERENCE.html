What this changes for leafgenix.in

The site currently in Desktop\Coding\leafgenix uses placeholder products that do not exist.

Swap the catalogue. Immunocore, Curcumin Prime, Ashwa Calm, Livgen, Omega Pure and Fembalance were invented as stand-ins. Replace them with the eight real nutraceuticals above — the database is built for exactly this, so it is a data change, not a code change.
Re-base the palette. The build uses bone / forest / lime, which is close in spirit but not exact. Move to #005C2D green with #ED940D orange as the accent so it matches the printed material.
Lead with the evidence. This deck is unusually citation-heavy — journal references, clinical-trial data, GOR grading tables. That is a real differentiator the website should use rather than generic wellness copy.
